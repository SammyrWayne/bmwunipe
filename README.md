# BMW Série 3 F30

Projeto desenvolvido em **HTML5** com o objetivo de apresentar informações básicas sobre a **BMW Série 3 F30** e praticar conceitos de desenvolvimento web.

## Sobre o projeto

A página apresenta informações sobre a BMW Série 3 F30, incluindo características do veículo, motorização e outros dados relacionados ao modelo.

O projeto também utiliza elementos semânticos do HTML5 para melhorar a organização e a estrutura da página.

## Tecnologias utilizadas

* HTML5
* Git
* GitHub

## Estrutura HTML

Foram utilizados elementos semânticos como:

* `<header>`
* `<main>`
* `<section>`
* `<footer>`
* `<form>`

Também foi utilizada uma hierarquia adequada de títulos com `<h1>` e `<h2>`.

## Formulário

O projeto possui um formulário relacionado ao tema da página, permitindo a interação do usuário.
